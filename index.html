About this course

This is a first-year introduction to how computers work and how they are beginning to think. We start from the smallest idea — a single bit — and build up, step by step, to the ideas behind modern artificial intelligence.

Each chapter is a single web page that you can open on any device. Wherever a topic is easier to see than to read about, it becomes a small animation you can play and replay at your own pace. No installation and no internet connection are needed once a chapter has opened.

What each lecture covers

A one-line preview of all nine lectures.

  1. Information & Data RepresentationHow computers store everything as bits and bytes — number systems, binary, and how text, numbers and images become data.
  2. Computer ArchitectureInside the machine — the Von Neumann model, the CPU, memory, the operating system and the GPU.
  3. AlgorithmizationTurning a problem into precise step-by-step instructions — control flow, and classic search and sorting methods.
  4. Software Life Cycle & DevelopmentHow real software is built — compilation vs. interpretation, testing and debugging, Agile, and version control with Git.
  5. Information SecurityKeeping data safe — the CIA triad, common threats, cryptography, and how systems check who you are.
  6. Computer NetworksHow machines talk to each other — the OSI and TCP/IP models, IP addresses, protocols, and the web.
  7. Introduction to AIWhat artificial intelligence is — the artificial neuron, neural networks, and how a machine learns.
  8. The Mathematics of Machine LearningThe math behind learning — loss functions, gradient descent, and how a model's weights are updated during training.
  9. AI in Practice — OverviewA closing tour of how artificial intelligence is used in the real world today.

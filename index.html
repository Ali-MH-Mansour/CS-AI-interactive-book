How this book worksكيف يعمل هذا الكتاب

Each lecture comes in two matching versions. This interactive version animates every process that a still page cannot show — a number turning into binary, a carry rippling through an addition, bits pouring into a byte — and adds a short commentary on what to notice in each animation. The text reference (the printable / PDF handout) carries the same wording, so the two never disagree.

Use the language switch (top-right) to read any page in English or العربية. Each chapter is a single self-contained page: no install, no internet needed once opened, and it publishes to GitHub Pages as one link.

تأتي كلّ محاضرة في نسختين متطابقتين. هذه النسخة التفاعلية تُحرّك كل عمليةٍ تعجز الصفحة الساكنة عن إظهارها — عددٌ يتحوّل إلى ثنائي، وحملٌ يسري خلال عملية جمع، وبتّاتٌ تُسكب داخل بايت — وتُضيف تعليقًا موجزًا على ما ينبغي ملاحظته في كل حركة. أمّا المرجع النصّي (المذكّرة القابلة للطباعة/PDF) فيحمل الصياغة نفسها، فلا تختلف النسختان أبدًا.

استخدم مبدّل اللغة (أعلى اليمين) لقراءة أي صفحة بالـالإنجليزية أو العربية. كل فصلٍ صفحةٌ واحدة مكتفية بذاتها: بلا تثبيت، وبلا حاجةٍ إلى الإنترنت بعد فتحها، وتُنشَر على GitHub Pages برابطٍ واحد.
